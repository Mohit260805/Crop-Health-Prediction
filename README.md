# 🌾 AI-Based Crop Health Prediction Using Machine Learning

## 📌 Project Overview

This project uses Machine Learning techniques to predict crop health based on agricultural, environmental, soil, and remote sensing data. The system helps farmers and researchers monitor crop conditions and support smart farming decisions.

## 🚀 Features

- Crop Health Classification
- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Data Visualization
- Machine Learning Model Training
- Crop Health Prediction
- Streamlit Web Application

## 📂 Dataset

🌐 **Dataset:** https://www.kaggle.com/code/valentinohartanto/crop-health-eda/input?select=agriculture_dataset.csv

📈 Features: NDVI, SAVI, Soil Moisture, Temperature, Humidity, Rainfall, Crop Health Label

💾 Format: CSV

## 📊 Dataset Features
